# Frontend

Next.js App Router application, isolated from the backend package and image. Phase 0 displays platform health through the API. Incident review screens and approval actions are planned for Phase 6.

```sh
npm ci
npm run dev
npm run typecheck
npm run build
```

Set `INTERNAL_API_URL` to the server-side API URL when it differs from `http://localhost:8000`. Compose supplies `http://api:8000`.
